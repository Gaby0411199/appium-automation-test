# 📱 Automatización Mobile con Appium

Proyecto de automatización de pruebas mobile usando Appium + WebdriverIO.

## 🚀 Tecnologías usadas

- Node.js
- Appium
- WebdriverIO
- Android Emulator

## 🧪 Caso de prueba

El test automatiza:

- Apertura de la app Settings
- Interacción con el buscador
- Escritura de texto (simulación de login)
