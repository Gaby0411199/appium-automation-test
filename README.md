\# 📱 Automatización Mobile con Appium + Page Object Model



Proyecto de automatización de pruebas mobile usando Appium + WebdriverIO, implementando \*\*Page Object Model (POM)\*\*.



\## 🚀 Tecnologías usadas



\- Node.js

\- Appium

\- WebdriverIO

\- Android Emulator

\- Page Object Model (POM)



\## 🧪 Caso de prueba



El test automatiza:



\- Apertura de la app Settings

\- Interacción con el buscador

\- Escritura de texto (simulación de login)

\- Validación del texto escrito
